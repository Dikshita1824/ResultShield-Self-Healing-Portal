RESILIENCE TESTING / 06

Chaos Lab.

Prepare and inspect controlled resilience tests.

SAFETY NOTICE: These buttons currently record test requests in the dashboard only. They do not crash the backend, disconnect MongoDB or create real traffic load. No recovery is counted from a simulated event.

01 / Backend availability

Check whether the application health endpoint responds. This is a normal health check, not a crash injection.

02 / Database connectivity

Test the student records endpoint to observe whether database-backed access works.

03 / Transient connection failure

Planned test: simulate a temporary database connection issue and verify retry behaviour. Backend retry logic is not yet connected to this button.

04 / Traffic spike

Planned test: send controlled concurrent requests and measure response times. Rate limiting and load tests must be implemented separately.

05 / Invalid student record

Planned test: validate a deliberately invalid record and verify quarantine behaviour. This button does not alter any database record.
